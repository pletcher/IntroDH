# Introduction to Digital Humanities – Midterm Exam

Please complete both parts of the midterm by the end of class.

## Part 1 – 1 hour, 5 points

Choose one of the projects from the 2025 DH awards: http://dhawards.org/dhawards2025/results/.

Submit a 1– to 2–page evaluation _by the end of class_. Some questions you might ask/answer:

- Who is the intended audience?
- How well does the project meet that audience's needs?
- Who funds the project?
- Does the project seem to have a plan for longevity?
- Is the project bug-free? Is it easy to use?

These questions are not exhaustive. The overall goal is to ask yourself what the project
is for, and how well it achieves its own stated goals.

You may not use the same project that you used for the collaborative DH project review.

## Part 2 – 1 hour, 5 points

In Colab, write a program that reads a JSON file containing JSON with the following
format:

```json
[{
    "urn": "urn:cts:greekLit:tlg0012.tlg001:1.1",
    "text": "Sing, O goddess, the anger of Achilles son of Peleus"
}, {
    "urn": "urn:cts:greekLit:tlg0012.tlg001:1.2",
    "text": "that brought countless ills upon the Achaeans"
}]
```

(Note that the list of objects might be longer than shown above.)

Your program should `print()` every word from the `"text"` fields of
the JSON objects, prefixed by its citation (the part following the
final colon of the `"urn"` field) and a space.

Assume well-formed input. You may split on whitespace.

For example, the first object above might become

```
1.1 Sing,
1.1 O
1.1 goddess,
1.1 the
1.1 anger
1.1 of
1.1 Achilles
1.1 son
1.1 of
1.1 Peleus
```
