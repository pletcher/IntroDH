2. What will the following code print?

```python
from lxml import etree

my_xml = """
<foo>
    <bar n="4">
        <baz n="1" />
        <baz n="2" />
        <baz n="3" />
    </bar>
    <bar n="5">
        <baz n="1" />
        <baz n="2" />
        <baz n="3" />
    </bar>
</foo>
"""

tree = etree.fromstring(my_xml)

for baz in tree.iterfind(".//baz"):
    print(baz.get("n"))
```
